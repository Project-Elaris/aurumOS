Current image
-------------

The current profile describes **|iso-name| |iso-version|** for
**|architecture|**, with **|boot-modes|** boot modes. The release channel is
**|iso-state|**. This information is read from ``archiso/profiledef.sh`` when
the site is built.

* `Get an ISO <download.html>`_ and read the `first-run guide <using.html>`_.
